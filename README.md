# 🎨 CCS · Creative Craft Studio (구 니치 레이더)

> **수집이 아니라 생산을 위한 레이더.** 국내 인기 차트와 레퍼런스 채널에서 "터진 영상"을 자동으로 찾아 점수를 매기고, 매일 **생산 큐 후보 3건 + 판정 카드**로 내놓습니다. 기획서: `docs/ⓒ_유튜브니치레이더_기획서_v2.1_20261104.md`

| 항목 | 값 |
|---|---|
| 화면 주소 | https://kaycomm21.github.io/niche-radar/ (저장소 공개 + Pages 설정 후 동작) |
| 갱신 | 매일 06:00 KST 자동 (GitHub Actions `daily-radar`) |
| 비용 | 0원 (YouTube API 무료 쿼터 + GitHub 무료 기능만 사용) |

## 1. 영근님 사용법 (하루 15분)

| 순서 | 할 일 |
|---|---|
| 1 | 휴대폰으로 화면 주소 열기 → **🎯 오늘** 탭 |
| 2 | 후보 3건의 점수·레시피를 보고 **▶ 생산 큐로 / 보류 / 폐기** 중 하나 누르기 |
| 3 | GitHub의 "새 Issue" 화면이 미리 채워진 채로 열림 → 초록 **Submit new issue** 버튼만 누르기 (메모는 선택) |
| 4 | 1~2분 뒤 자동 기록(`exports/verdicts.json`, 생산 큐는 `exports/production_queue.json`)되고 화면이 다시 만들어짐 |

- 판정하지 않은 카드는 **7일 뒤 자동 보관**됩니다(삭제 아님, 홈 맨 아래 "📦 자동 보관").
- 순위 화면의 **수집 제외**를 누르면 그 채널은 다음 수집부터 빠집니다.
- 레퍼런스 채널에서 10배↑ 영상이 새로 나오면 GitHub Issue 알림(라벨 `alert`)이 하나 생깁니다. GitHub 앱 알림을 켜 두면 휴대폰으로 옵니다.

## 3. 지표 정의 (화면의 ⓘ 와 동일)

| 지표 | 산식 |
|---|---|
| 아웃라이어 배수 | 영상 조회수 ÷ 같은 채널 최근 30편(같은 포맷, 5편 미만이면 전체) 조회수 중앙값 |
| 🔥 조회수 터짐 | 배수 ≥ 3, 또는 업로드 7일 이내 국내 인기 차트 진입 |
| 💰 수익화 터짐 | 롱폼 8분↑ + 고RPM(카테고리 RPM 상한 ≥ 5,000원 또는 금융·건강 키워드) + 업로드 30일 이내 + 배수 ≥ 2. 구독 10만 미만 채널이면 +5점 |
| 📣 이슈화 | (Phase 1: 유튜브 지표만) 24시간 조회 증가가 추적 영상 상위 5% + 24시간 댓글 증가율 ≥ 10% |
| 재가공 가치 점수 | 터짐 강도 25 + 수익성 20 + 내 채널 적합도 20(**AI, Phase 2 — 지금은 비움**) + 재현 난이도(역) 15 + 수명 10 + 정책 안전 10 → **Phase 1은 80점 만점**. 짜깁기(하이라이트·명장면·리액션 모음 등) 의존 포맷은 0점·큐 제외 |
| 투명 등급 S~D | 성장률 30 + 조회 효율 25 + 참여율 20 + 업로드 일관성 15 + 아웃라이어 빈도 10. 각 항목 = 유니버스 내 백분위 × 배점, 데이터 없는 항목은 빼고 100점 환산. S≥85 A≥70 B≥55 C≥40 |
| 예측 | Holt 선형 지수평활(α·β 격자 탐색). 일별 데이터 7일 이상부터. **모델 예측, 보장 아님** |
| 예상 광고 수익 | 최근 30일 업로드 조회 × RPM(`config/rpm_kr.yaml`) ÷ 1000. **추정치 — RPM 값은 실측이 아닌 초기 가정치** |
| ⚠️ 이상 신호 | 최근 영상 평균 조회 ÷ 구독 < 5% (NoxInfluencer 공개 기준 인용), 구독 급증 대비 조회 정체 |
| 쇼츠 판정 | 60초 이하, 또는 180초 이하 + `#shorts` 표기 (API에 쇼츠 여부 필드가 없어 추정) |

## 4. 하루 쿼터 예상표 (예산 8,000 / 기본 10,000유닛)

| 유니버스 | 인기차트 | channels.list | playlistItems | videos.list | 합계(유닛/일) | 예산 8,000 대비 |
|---:|---:|---:|---:|---:|---:|---:|
| 100 | 60 | 2 | 100 | 60 | 222 | 3% |
| 500 | 60 | 10 | 500 | 300 | 870 | 11% |
| 1,000 | 60 | 20 | 1,000 | 600 | 1,680 | 21% |
| 2,000 | 60 | 40 | 2,000 | 1,200 | 3,300 | 41% |
| 3,000 | 60 | 60 | 3,000 | 1,800 | 4,920 | 62% |

- 인기 차트 15개 카테고리 × 최대 4페이지 = 60유닛 (차트가 없는 카테고리는 1유닛만 쓰고 건너뜀)
- 채널당 약 1.6유닛(업로드 목록 1 + 영상 통계 0.6) → **상한 2,000채널이어도 약 3,300유닛(41%)**
- `search.list`(100유닛)는 자동 실행하지 않음. Actions → daily-radar → Run workflow → `search_q` 입력 시에만, 하루 20회 상한
- 모든 호출은 `quota_log` 테이블에 엔드포인트별로 기록되고, 예산을 넘기기 **전에** 수집을 멈춥니다

## 5. 채널 추가 방법

`seed/refs_channels_verified_20261017.json` 에 아래 형식으로 넣고 커밋하면 다음 수집부터 반영됩니다. 키(그룹 이름) = 내 채널 이름.

```json
"경제적자유구역": [
  { "q": "메모용", "channel": "채널명", "url": "https://www.youtube.com/channel/UCxxxxxxxxxxxxxxxxxxxxxx", "subs": null }
]
```
- `url` 이 `channel/UC…`(24자) 형식이 아니면 제외되고, 제외 목록은 📐 정의 탭에 표시됩니다 (현재 5건: Graham Stephan, Soft Room, 온라인 탑골공원, 핑크퐁, 판타소너).
- 인기 차트에 등장한 채널은 자동 편입(상한 2,000)되고, 30일 무업로드·무갱신이면 자동 비활성됩니다.

## 6. 실행 방법

| 상황 | 방법 |
|---|---|
| 평소 | 아무것도 안 해도 매일 06:00 자동 |
| 지금 바로 수집 | GitHub → Actions → daily-radar → Run workflow (mode: auto) |
| 화면만 다시 만들기 | 같은 화면에서 mode: export (API 0유닛) |
| 키 없이 가짜 데이터로 화면 확인 | mode: fixture (DB에 저장 안 함) |

로컬(개발용):
```bash
python -m radar demo --days 40      # 키 없이 40일치 가짜 데이터
python -m pytest -q                 # 테스트
cd web && npm ci && npm run dev     # 화면 (http://localhost:5173)
```
`YOUTUBE_API_KEY` 환경변수가 있으면 `python -m radar daily` 가 실제 수집, 없으면 자동으로 fixture 모드입니다.

## 8. 데이터 보존 정책

> ⚠️ **확인 상태**: YouTube API 서비스 약관·개발자 정책의 데이터 보관 조항 원문을 이 작업 환경에서 열지 못했습니다(네트워크 차단). 아래는 보수적으로 잡은 기본값이며, **영근님이 원문(https://developers.google.com/youtube/terms/developer-policies)의 "storing/caching" 조항을 확인한 뒤 확정**해야 합니다.

| 데이터 | 보존 | 설정 |
|---|---|---|
| 영상 일별 스냅샷 (`video_daily`, 업로드 30일 이내 영상만) | 14일 | `VIDEO_SNAPSHOT_DAYS` |
| 인기 차트 기록 (`chart_daily`) | 30일 | `CHART_RETENTION_DAYS` |
| 영상·채널 메타데이터 | 매일 갱신, **30일 동안 갱신 못 하면 삭제/비활성** | `STALE_DAYS` |
| 채널 일별 통계 (`channel_daily`) | 365일 (기획서 기준) — **약관이 30일 갱신 규칙을 요구하면 env `RADAR_SNAPSHOT_DAYS=30` 으로 줄일 것** | `SNAPSHOT_RETENTION_DAYS` |

- 영상·음성은 다운로드하지 않습니다. 메타데이터와 썸네일 **URL**만 저장합니다.
- API 키는 Actions secret `YOUTUBE_API_KEY` 에만 있고, 코드·로그·에러 메시지에 출력하지 않습니다(테스트로 검증).

## 9. 폴더 구조

```
radar/        파이썬 (표준 라이브러리만)
  collect.py    일간 수집 · 보존 정리
  youtube.py    실제 API 클라이언트 + fixture(가짜) 클라이언트
  quota.py      쿼터 로거 · 예산 차단
  metrics.py    배수·라벨·점수·등급·Holt 예측 (순수 함수)
  export.py     DB → 화면용 JSON
config/rpm_kr.yaml   RPM 가정치 (편집 가능)
web/          Vite + React + TS 화면 (모바일 375px 우선, 다크모드)
exports/      판정 기록 (verdicts.json, production_queue.json) — Phase 2 생산 패키지 입력
tests/        pytest (API 응답 fixture · 지표 · 전체 파이프라인)
```
