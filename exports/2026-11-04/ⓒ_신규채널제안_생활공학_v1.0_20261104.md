| 포맷 | 얼굴 없음 · 내레이션 + B롤 + 도해 → **재현 난이도 낮음** | 재가공 점수 '재현성' 13/15 |
| 수익성 | 과학기술 카테고리(28) RPM 가정치 2,000~6,000원 (가정, 실측 아님) | config/rpm_kr.yaml |

## 2. 허점 먼저 (솔직한 판단)
| 리스크 | 내용 | 대응 |
|---|---|---|
| 표본 1채널 | 4편 대박이 **한 채널의 알고리즘 운**일 수 있음 | 30일 레이더에서 **다른 채널 3곳 이상**이 같은 패턴을 보일 때만 론칭 |
| 사실 오류 위험 | 공학 주제는 틀리면 댓글로 바로 지적당함 | 팩트체크 필수 단계 (이번 파일럿도 출처 포함) |
| 채널 수 과다 | 영근님 채널이 이미 10개 이상 → 집중력 분산 | 신규 채널 대신 **히스토리X 내 "기술의 역사" 코너**로 먼저 테스트 |
| B롤 비용 | 기체 내부 장면을 Flow/Veo로 만들어야 함 (크레딧 소모) | 도해(인포그래픽) 비중을 높여 생성 B롤 최소화 |
