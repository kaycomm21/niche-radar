## §A. 결과물 의무 원칙 (모든 모듈 공통, 슬롭 방지)
| 규칙 | 내용 |
|---|---|
| A1 | 모든 수집은 반드시 3가지 중 하나로 끝난다: **① 판정 카드**(채택/보류/폐기 버튼) **② 생산 큐 항목**(대본·영상 단계로 자동 진입) **③ 자동 실행**(알림·업로드·갱신). 표만 쌓는 화면은 만들지 않는다 |
| A2 | 화면 첫 페이지 = "오늘의 생산 큐 3건"과 "판정 대기 카드". 순위표·그래프는 근거 링크로만 노출 |
| A3 | **수집 중단 규칙**: 30일 동안 생산 큐로 이어진 비율이 10% 미만인 수집 항목(카테고리·채널 그룹·키워드)은 자동으로 수집 중단 후보 → 월간 보고에 표시 |
| A4 | 판정 카드는 7일 무응답 시 자동 보관(삭제 아님) |
| A5 | KPI는 "수집량"이 아니라 **"업로드된 영상 수·그 영상의 수익"**으로만 잰다 |

## §0-1. M0 💰 수익화 콘텐츠 공장 (핵심 중의 핵심)

### 흐름
```
[히트 DB] → [재가공 가치 점수] → [레시피 선택] → [생산 패키지 자동 생성] → [로컬 생산 라인] → [비공개 업로드] → [영근님 1클릭 공개] → [7일 성과 → 레시피 가중치 학습]
```

### 1) 히트 DB — 3종 "터짐" 라벨 (자동 판정)
| 라벨 | 판정식 (초안, 30일 운영 후 보정) |
|---|---|
| 🔥 조회수 터짐 | 아웃라이어 배수 ≥ 3 (채널 최근 30편 중앙값 대비) 또는 업로드 7일 내 국내 인기 차트 진입 |
| 💰 수익화 터짐 | 롱폼(8분↑, 중간광고 가능) + 고RPM 카테고리(금융·재테크·교육·건강·IT 등, `rpm_kr.yaml` 상위) + 30일 조회 급증. **특히 구독자 10만 미만 채널의 대박 = "작은 채널도 된다" = 재현 가능성 높음** 가중 |
| 📣 이슈화 | 24시간 조회 증가 상위 + 댓글 증가율 급등 + **Brave 검색으로 같은 주제의 뉴스·커뮤니티 언급 확인**(§B) → 수명 짧음(이슈) / 길음(에버그린) 분류 |

### 2) 재가공 가치 점수 (100점) — 생산 큐 우선순위
| 항목 | 배점 | 산식 |
|---|---|---|
| 터짐 강도 | 25 | 배수·차트 순위·24h 증가 |
| 수익성 | 20 | 카테고리 RPM × 길이 적합도 (M4 실측 RPM으로 보정) |
| 내 채널 적합도 | 20 | 채널 바이블 키워드·톤 유사도(Gemini Flash 판정) |
| 재현 난이도(역) | 15 | 얼굴 출연·현장 촬영 필요 = 감점, 내레이션+B롤로 가능 = 가점 |
| 수명 | 10 | 에버그린 가점, 이슈는 48시간 내 생산 가능할 때만 가점 |
| 정책 안전 | 10 | 실존 인물 비방·저작물 의존·의료/금융 단정 = 감점. **재사용 콘텐츠(원본 짜깁기)로 판정되면 0점·큐 제외** |

## §C. 시장 포지셔닝
- 블링·녹스·플레이보드의 주 고객은 **광고주·대행사·MCN**(인플루언서를 "사는" 쪽, 회사 자료 기준). 이들은 "누가 큰가"를 판다.

## 0. 결론
- 상용 사이트의 기능을 **"공개 API로 재현 가능한 것 / 추정만 가능한 것 / 불가능한 것"**으로 나누면, 70%는 재현 가능하다.
- 그들이 못 하는 것 3개가 우리의 킬러다: ① **내 채널의 실제 수익·시청지속(YouTube Analytics OAuth)** ② **AI가 "왜 터졌나"를 해부하고 내 채널용 기획안으로 바꿔줌** ③ **콘텐츠 생성기(make_episode·VideoGen OS)로 바로 넘김.**
- 불가능: 전 세계 수백만 채널 전수 DB(블링·소셜블레이드 규모). → **"관심 시장 유니버스" 2,000채널 + 국내 인기 차트 전체**로 대체.
- 클라우드 크레딧 $93으로는 **Phase 1(시장 분석 코어)**까지. Phase 2·3은 매달 들어오는 GCP 크레딧(₩113,451 잔액)과 로컬 CC로 이어간다.

## 4. 아키텍처

```
[GitHub Actions cron]  06:00 일간 수집 / 월 06:00 주간 / 수동 dispatch
   ├─ collector (Python 3.11): YouTube Data API v3 → SQLite (data 브랜치, 일별 스냅샷 테이블)
   ├─ analytics: 지표·등급·Holt 예측·아웃라이어 계산 → 화면용 JSON 집계(채널별·차트별) 생성
   └─ ai (Phase 2): Vertex Gemini Flash(GCP 크레딧) → 해부 결과 캐시
[GitHub Pages] Vite + React + TS 정적 웹앱 (모바일 우선·다크모드), 집계 JSON만 읽음
[로컬 CC] 내 채널 OAuth(M4)·exports → 콘텐츠 생성기 연결
```
- 서버·DB 비용 0원(Phase 1). 비밀키는 Actions secret만: `YOUTUBE_API_KEY`(Phase 1), `GCP_SA_KEY`(Phase 2).

- 약관: 메타데이터만, 영상·음성 다운로드 금지, 썸네일은 URL 링크.
